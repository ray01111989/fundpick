# FundPick

An AI-powered ETF and mutual fund screener. Answer four questions about what you want, and FundPick returns four fund suggestions with a plain-English explanation of why each one fits.

It uses the Google Gemini API through a small Vercel serverless function, so the API key never reaches the browser.

## What you get

For each request, the app returns:

- A short **market context** paragraph for the chosen category
- **Four ranked funds**, each with name, ticker, type (ETF or mutual fund), issuer, expense ratio, category tag, a fit score, a key metric, who it is best for, and the main drawback

## Inputs

| Field | Meaning |
|---|---|
| `category` | Fund category you are interested in |
| `risk` | Your risk tolerance |
| `horizon` | Your time horizon |
| `goal` | Your primary goal |

## Tech stack

- Static front end (`index.html`)
- Vercel serverless function (`api/analyze.js`), Node
- Google Gemini API (generative language REST API)

## How the API works

`POST /api/analyze` with a JSON body containing the four fields above.

The function builds a prompt, asks Gemini which models are currently available, then tries the available `flash` and `pro` models one after another until one returns valid JSON. The response includes `_model` so you can see which model answered. If every model fails, it returns a `500` with the last error and the list of models it tried.

## Run and deploy

1. Create a free API key in [Google AI Studio](https://aistudio.google.com/).
2. Deploy to Vercel:

```bash
npm i -g vercel
vercel
```

3. In the Vercel project settings, add the environment variable `GEMINI_API_KEY`, then redeploy.

To run locally with the serverless function:

```bash
echo "GEMINI_API_KEY=your_key_here" > .env
vercel dev
```

## Disclaimer

FundPick is an educational project. Fund names, expense ratios, and returns are generated by a language model and **may be inaccurate or out of date**. This is not financial advice. Verify every detail with the fund issuer before investing.
